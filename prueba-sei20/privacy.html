Privacidad de la Agenda de la Sala de Samuel

La Agenda conecta la Sala personal con Google Calendar para consultar calendarios y ver, crear y editar eventos. El permiso de Google también permite borrar eventos, pero la Sala no ofrece esa función.

La base de datos guarda el token de renovación y la configuración de conexión. No guarda copias de tus eventos. El navegador recuerda los calendarios seleccionados.

Los datos se usan para gestionar la agenda, no se venden ni se usan para publicidad. El acceso está limitado a la cuenta de Samuel. Los proveedores técnicos son Google, Supabase y GitHub Pages.

El botón Desconectar elimina el token guardado y detiene el acceso desde la Sala, sin modificar eventos. No revoca el permiso en Google: eso se hace desde los permisos de la cuenta de Google.
